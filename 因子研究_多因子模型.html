一、这次改了什么 / 为什么这么做

v2 的死结是：风控成立、选股无 alpha。单一反转因子在随机选股对照里 排第 10 百分位——它的收益 ≈ "市场平均 + 熊市空仓"，没有选股能力。
这一版不再依赖单一因子，而是建立多因子横截面模型：先用 rank-IC 验证每个因子是否真有预测力， 只把通过检验的因子合成进组合。这是把"单因子赌博"升级为"因子投资"的标准做法。
环节做法目的
因子库5 个经典因子：短期反转 / 中期动量 / 低波动 / 接近一年新高 / 时序趋势覆盖主要风格，且全部可由 OHLCV 历史计算（不掺假基本面）
方向固定每个因子方向由金融学理论定（fac.SIGNS），IC 只验证不去改禁止"看结果倒推方向"的作弊
选因子在样本内用 rank-IC 的 t 值筛选（方向对 + t>1.5）只用样本内信息决定因子集
验证样本外 / 成本 / 随机选股对照 / 滚动前推，全程不泄露给选因子真实检验 alpha
组合低频（半年频）+ 分散（Top20）+ 指数门控，沿用 v2 已证结论不重复 grid 搜参，避免新一轮过拟合

二、因子 rank-IC 检验

rank-IC = 因子横截面取值 与 未来 1 个月收益的 Spearman 相关系数。它能直接告诉我们：按这个因子排序选股，下一月到底有没有用。下表"方向IC"已按理论方向调整（正值=该因子指向的方向真能赚钱）。

八、持有期错配检验：为什么选股变成了负 alpha

因子 IC 是按月测的（预测未来 1 个月），但上面的 composite 是半年才调一次仓。信号说"下个月谁涨"，组合却要拿满半年——中间信号早就反转了。这是因子投资最常见的坑：IC 的预测周期 ≠ 持仓周期。下面把组合改成月度再平衡（匹配 IC 周期）看 alpha 是否翻转。

月度 composite 在滑点 0.50% 时收益 -6.06%。高换手下收益被成本严重侵蚀，实盘几乎不可行——这是月度化的致命伤。
月度化后，随机对照百分位从第 5 升到第 95。持仓周期对齐 IC 后，选股 alpha 显著改善——说明之前是'拿太久'吃掉了信号。

九、结论

判定：仍未超越随机，alpha 未证实

  • 入选因子：rev20、vol60（样本内方向 IC 为正且 t>1.5）。
  • 选股 alpha：composite 相对纯门控 -53.55pp；样本外超额 -36.95pp；随机对照第 5 百分位。
  • 仍未解决：幸存者偏差（退市股不在快照）、缺少基本面/估值因子（这是 alpha 的天花板）。
